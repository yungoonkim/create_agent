# 택배 v2 중단과 단일 진단 준비

두 사용자 아카이브의 안전한 경로/해시 검사를 마쳤다. 첫 `local-1794271452438-549a78b2`는 인증/권한 실패1시도·응답0이었다. ADC 로그인 뒤의 `local-1794271980331-b9076eca`는3시도·응답2이며 Reviewer가 고의 예외를 major 모순으로 찾아 수정 요청했고 실제 Writer v2를 작성했다. v2 일반 검토는 provider_or_network_failure로 중단됐다. 기존 자료는 [원압축 보존 폴더](acceptance/parcel-review-failure-20261110/)에 그대로 보관한다.

실패 요청 스키마는 약4678자/enum값78개이며 첫 성공 검토는 약3285자/enum값141개였다. 이 수치만으로 스키마 복잡도 오류를 확정할 수 없다. HTTP 상태·원인 코드가 저장되지 않았으므로 네트워크/서버/인수 오류 중 하나라고 단정하지 않는다. 기존 비용은 제공 지표 소계0.04921875USD이며 실패의 비용은 불명이다.

[새 도구](../examples/reviewer-diagnostic/README.md)는 원래 v2 요청을 변경하지 않고1회만 전송해 안전한 HTTP 상태/코드/고정 분류를 수집한다. raw 예외 메시지/헤더/스택은 기록하지 않는다. 기존 Writer·원문·승인·시작 예약을 재생하거나 수정하지 않는다. 모델 응답은 진단 자료이며 공식 Review/품질 통과로 사용하지 않는다. 응답 재사용·검증과 반례 검토가 필요하면 먼저 출처/버전/남은 예산을 별도 확인한다.

추가 실제 Gemini 호출은0회다. 오프라인 검사 후 새 진단 ZIP을 제공하며 사용자가 명시적 --run-live로 실행할 때만 최대1시도가 발생한다. 결과 요청 전에 권장 Codex 모델/생각 수준을 안내하는 사용자 선호를 AGENTS에 명시했다.
