# 사용자 선택과 승인 기록 — 할 일 시험

## 첫 질문 7개

- Q-1: 웹 브라우저에서 버튼을 눌러 사용
- Q-2: 제목·추가 메모·마감일
- Q-3: 수정과 삭제 모두 가능
- Q-4: 완료 취소 가능
- Q-5: 할 일과 완료한 일을 나누고, 각각 등록 순서로 표시
- Q-6: 같은 제목도 각각 별개의 할 일로 추가 가능
- Q-7: 내 컴퓨터에만 저장하면 되고, 세부 방식은 맡김

## Scope 승인

사용자는 Scope v6의 기능 요약과 상세 기획 점검 항목을 본 뒤 “응 그렇게 진행해줘.”라고 답했다. 이를 Scope v6 승인과 기획·검토 진행 허가로 기록했다. [Scope 승인 레코드](scope-approval.json)를 보존하며 아직 생성되지 않은 최종 기획이나 제품 구현 허가로 확장하지 않는다.

## 추가 상세 질문 3개

- DETAIL-1: 제목·마감일은 필수, 메모만 비워도 됨
- DETAIL-2: 날짜와 시간 — 예: 11월 10일 오후 3시까지
- DETAIL-3: ‘정말 삭제할까요?’ 확인 후 삭제

이 답변은 [기획 수정 요청](revision-v1-request.md)에 원문으로 전달했다. 기획 v1/기존 Review를 보존한 사용자·진행자 수정이며 Reviewer 자체 revise 요청으로 계산하지 않는다. 저장 오류·정렬 안정성·브라우저 유지 범위 등 나머지 품질 보완 요청은 진행자가 구분해 기록했다.
