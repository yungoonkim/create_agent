# Scope v6 — 내 할 일 목록 관리

**미승인 제안** · projectId: `supervisor-todo-acceptance-20261108` · Scope ID: `scope-v6` · version: 6

## 목표

혼자 사용하는 개인용 웹 브라우저 기반 할 일 관리 도구 기획 및 작업 지시서 수립 (할 일 등록·수정·삭제, 완료/완료 취소, 미완료·완료 분리 목록 조회, 로컬 데이터 저장)

## 포함할 기능

- **REQ-01**: 할 일 추가 기능: 제목, 추가 메모, 마감일을 입력받아 새로운 할 일 항목을 생성하며, 동일한 제목이 이미 존재하더라도 별개의 항목으로 중복 등록을 허용한다.
- **REQ-02**: 목록 분리 및 등록순 조회 기능: 아직 완료되지 않은 '할 일' 목록과 '완료한 일' 목록을 화면에서 구분하여 보여주고, 각각 등록된 순서대로 정렬하여 표시한다.
- **REQ-03**: 완료 및 완료 취소 전환 기능: 진행 중인 할 일을 클릭하여 완료 상태로 변경할 수 있고, 완료된 항목을 다시 진행 중(미완료) 상태로 되돌릴 수 있다.
- **REQ-04**: 할 일 정보 수정 기능: 이미 등록된 항목의 제목, 추가 메모, 마감일 내용을 확인하고 수정할 수 있다.
- **REQ-05**: 할 일 삭제 기능: 취소되거나 불필요해진 할 일 항목을 목록 및 저장소에서 완전히 삭제할 수 있다.
- **REQ-06**: 로컬 데이터 영속성 유지 기능: 웹 브라우저나 프로그램을 종료했다가 다시 실행해도 사용자의 컴퓨터에 저장된 할 일 데이터가 그대로 복원된다.
- **REQ-07**: 웹 브라우저 기반 사용자 인터페이스: 사용자가 웹 브라우저 화면에서 버튼 클릭과 입력 폼을 통해 모든 기능을 직관적으로 조작할 수 있다.

## 제외할 기능

- **EXC-01**: 다중 사용자 로그인 및 계정 관리: 개인 1인 사용 도구이므로 회원가입, 로그인, 다중 계정 분리 기능은 제외한다.
- **EXC-02**: 원격 클라우드 서버 동기화 및 공유: 데이터는 사용자 개인 컴퓨터에만 보관하며, 외부 서버 업로드나 타인과의 할 일 공유 기능은 제외한다.
- **EXC-03**: 고급 검색 및 복합 정렬: 마감일 임박순 정렬, 중요도/우선순위 필터, 태그 분류 및 키워드 검색 기능은 이번 범위에서 제외한다.
- **EXC-04**: 이번 시험 세션 중의 실제 코드 구현 및 실행: 본 세션은 기획 및 작업 지시서 작성 품질을 검증하는 시험이므로, 실제 프로그램 코드 작성 및 팀원 에이전트 실행은 제외한다(향후 구현을 위한 작업 지시서 작성은 포함).

## 기술·표현 조건

- 웹 브라우저 환경에서 버튼 클릭과 폼 입력으로 동작하는 사용자 화면을 전제로 기획한다.
- 외부 서버 없이 사용자의 로컬 환경(예: 웹 브라우저 내부 로컬 저장소 등)에만 데이터를 영속 보관하도록 설계한다.
- 기획안과 작업 지시는 쉬운 한국어와 일상적인 사용 예시(예: '장보기 추가 → 목록 확인 → 완료 표시 → 재접속 시 유지')를 중심으로 작성하며, 기술 용어는 별도 절에서 설명을 덧붙인다.
