Reviewer 검토 4회 모두 pass, 자체 revise 0회다. v1 이후의 3회 수정은 사용자 추가 답변·진행자 내용 점검으로 요청했다. Reviewer의 pass만으로 누락이 모두 발견됐다고 해석하지 않는다. 실제 제품 코드와 제품 시험이 없으므로 여기서 제시한 AC는 향후 구현 결과를 검수할 기준이다.

직접 구현할 때는 기획의 타입/달력/정렬/손상 조건을 구체적인 검증 명령으로 연결하고, 저장 접근 오류·commit 전후 실패·같은 고정 주소 제공 절차를 작업 지시에서 확인해야 한다. 이 단계에서는 작업 지시도 아직 생성하지 않았다. 기획 후보는 사용자가 승인하기 전까지 미승인이다.
