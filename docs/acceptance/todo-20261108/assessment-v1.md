# 진행자 점검 — 할 일 기획 v1

Gemini Reviewer는 pass / issues 0을 반환했다. suggestions에 메모·마감일의 선택 입력 여부와 삭제 확인을 작업 지시 단계에서 구체화하라고 권고했다. 이 기록을 덮어쓰거나 Reviewer가 수정 요청한 것으로 바꾸지 않는다.

진행자는 현재 기획 최종 승인 전에 보완이 필요하다고 판단했다.

1. 제목·메모·마감일 필수 여부와 날짜/시간 포함 여부가 미확정이다. 사용자가 선택하도록 세 가지 쉬운 질문(입력 필수, 날짜/시각, 삭제 확인)을 전달했다. 실제 답변 전에는 확정하지 않는다.
2. 삭제 확인을 변경 요약에서 언급하지만 본문은 즉시 삭제 기준, 열린 결정에서는 미정이라고 한다. 선택 후 취소/확인 결과를 일치시켜야 한다.
3. 저장 용량 초과를 안내 제공 여부의 열린 결정으로 남겼다. 쓰기 실패 시 성공 표시·화면만 변경·원본 덮어쓰기를 방지하는 규칙이 필요하다.
4. 브라우저 내부 저장의 유지 범위를 설명하지 않았다. 같은 주소·브라우저·프로필의 일반 창 조건과 데이터 직접 삭제·비공개 창·기기/브라우저 변경의 한계를 쉬운 말로 안내해야 한다. 물리 전원 단절 무손실 등 보장하지 않는다.
5. 완료 취소와 정보 수정 후 원래 등록순 유지 및 같은 등록 시각의 순서, 동일 제목의 한 항목만 바꾸는 사례를 판정 가능한 조건으로 구체화한다.
6. 저장 JSON 손상/필드 오류/중복 ID 로드 시 원본 보존·오류 안내, 전체 저장 실패와 화면 반영 순서가 빠져 있다. 기술 절에 보완하고 사용자는 의미를 이해할 수 있는 예시로 설명한다.

이는 Reviewer 자체 revise가 아니라 진행자 검토로 찾은 보완 사항이다. 승인된 Scope v6와 이전 기획·검토 원문을 보존한 상태에서 request-plan-revision 경로로 수정하고 새 기획을 다시 검토한다. 제품 구현·팀원 실행은 하지 않는다.
