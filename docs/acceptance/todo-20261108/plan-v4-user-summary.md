# 내 할 일 목록 관리 — 기획안 v4 쉬운 요약

**이후 2026-11-09 사용자가 기획 v4를 승인했다.** [실제 승인 레코드](../todo-final-20261109/plan-approval.json), [최신 작업 지시](../todo-final-20261109/work-orders-easy-summary.md)를 따른다. 아래는 승인 전에 제시했던 요약 원문이다.

**최종 승인 대기**입니다. 아래는 [Gemini 기획안 v4 원문](plan-v4.md)의 사용자 검토용 요약입니다. 원문을 수정하거나 별도 기획 버전으로 대체하지 않습니다. [검토 결과](review-v4.json)는 pass이며, 실제 구현·제품 테스트를 완료했다는 뜻은 아닙니다.

## 이렇게 사용합니다

1. 브라우저에서 할 일 관리 화면을 엽니다.
2. **제목과 마감 날짜·시간은 반드시 입력**합니다. 메모는 비워도 됩니다. 예: ‘장보기 / 11월 10일 오후 3시 / 사과 3개’.
3. ‘추가’를 누르면 미완료 목록에 나타납니다. 같은 제목도 각각 별개의 할 일로 추가됩니다.
4. ‘완료’를 누르면 완료 목록으로 이동합니다. ‘완료 취소’를 누르면 원래 목록으로 돌아옵니다. 두 목록 모두 처음 등록한 순서를 유지합니다.
5. ‘수정’으로 제목·메모·마감 날짜와 시간을 바꿉니다. 같은 제목이 여러 개라도 선택한 항목만 바뀝니다.
6. ‘삭제’를 누르면 **‘정말 삭제할까요?’**라고 묻습니다. 확인하면 해당 항목만 지우고, 취소하면 그대로 둡니다.
7. 같은 컴퓨터의 같은 브라우저·프로필에서 같은 주소를 다시 열면 내용이 남아 있습니다.

## 실수나 오류가 생기면

- 제목이 공백뿐이거나 마감 날짜·시간이 없으면 저장하지 않고 이유를 알려줍니다. 작성 중인 내용은 남깁니다.
- 2월 30일처럼 실제로 없는 날짜나 잘못된 시간은 거부합니다.
- 저장에 실패하면 성공했다고 표시하지 않고, 이전 목록과 입력 내용을 유지합니다.
- 저장 데이터가 잘못된 상태라면 멋대로 빈 목록으로 바꾸거나 덮어쓰지 않고, 경고하고 변경을 막습니다.
- 저장은 됐지만 화면 표시만 실패했다면 그 사실을 알리고 새로고침으로 다시 불러오게 합니다.

## 이번에 함께 승인받을 설계 제안

- **지난 마감 날짜·시간도 등록 가능**하게 합니다. 날짜와 시간은 적은 그대로 표시하고 기한 경과 표시·알림은 넣지 않습니다.
- **한 브라우저 탭에서 차례로 사용**하는 도구로 설계합니다. 여러 탭의 동시 편집은 지원하지 않습니다.
- 데이터는 **브라우저 내부에만 저장**합니다. 다른 기기·브라우저와 공유되지 않습니다. 브라우저의 사이트 데이터를 직접 삭제하거나 비공개 창을 사용하면 내용이 없어질 수 있습니다.
- 저장 데이터 형식·검증·등록 순번 등 구현 세부사항은 원문 기술 절(5절)의 설계 제안을 따릅니다. 이 부분은 사용자 직접 선택과 구분해 기록했습니다.

로그인·클라우드 동기화·검색·마감일순 정렬·알림은 추가하지 않습니다. **기획안을 승인하면 다음은 작업 지시서 제안·품질 점검이며, 제품 구현이나 팀원 Agent 실행은 하지 않습니다.**
