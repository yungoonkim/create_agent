# 할 일 관리 — 작업 지시 쉬운 요약

기획안 v4는 사용자가 승인했다. 아래는 그 기획을 미래 구현 작업 6개로 나눈 제안이며, 실제 앱이나 팀원을 실행한 것은 아니다.

| 순서 | 할 일 | 확인할 결과 |
| --- | --- | --- |
| 1 | 앱을 열 주소와 검사 환경 준비 | 항상 같은 주소로 열고, 다른 포트로 몰래 바꾸지 않기 |
| 2 | 입력과 등록 순서 규칙 만들기 | 제목·마감 날짜/시간 필수, 메모 선택, 같은 제목도 별개로 등록 |
| 3 | 저장과 불러오기 만들기 | 정상적으로 껐다 켜면 복원, 잘못된 데이터는 덮어쓰지 않기 |
| 4 | 입력창과 두 목록 만들기 | 미완료/완료를 나누고 원래 등록 순서로 표시 |
| 5 | 완료·취소·수정·삭제 버튼 연결 | 고른 항목만 변경, 삭제 전에 확인, 취소하면 그대로 |
| 6 | 전체 연결과 오류 상황 확인 | 저장 실패 시 입력 보존, 저장 후 화면 실패는 새로고침 안내, 같은 브라우저 프로필로 재실행 복원 확인 |

각 작업은 앞 작업을 먼저 마친 뒤 진행하도록 연결했다. [상세 지시](work-orders-v2.md)에 파일·완료 조건·미래 검사 방법을 담았다. 브라우저 내부 저장이므로 사이트 데이터를 직접 지우거나 다른 기기/브라우저로 바꾸면 내용이 유지되지 않을 수 있고, 여러 탭 동시 편집은 지원하지 않는다.

이번 시험은 여기까지다. 작업 초기화·제품 코드 작성·제품 브라우저 테스트·팀원 Agent 실행으로 자동 진행하지 않는다.
