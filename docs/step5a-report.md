- 모델: 통합 흐름은 Fake Writer/Reviewer 및 고정 제안 fixture. Gemini 제안 어댑터는 SDK client mock으로 검증

## 무엇을 연결했는가

1. 최초 요구를 공백·개행까지 보존하고 질문·답변을 별도 저장한다.
2. 중요한 질문에 답한 뒤 Scope를 제안한다. 승인 전 기획은 실행되지 않는다.
3. Scope 거절은 별도 기록하며 다음 제안은 새 버전으로 만든다.
4. 승인 Scope와 원문·답변을 기존 Writer/Reviewer에게 전달한다. 테스트에서는 Plan v1 수정 요청 → v2 검토 통과 → 사용자 최종 승인 대기를 확인했다.
5. 해당 Plan 버전을 명시적으로 승인해야 작업 분해를 허용한다.
6. 제안 작업의 요구 ID 전체 커버리지·DAG·산출물 경로·초기 상태를 검사하고 승인 기획 해시에 연결한다.
7. 지시서에 승인 기획·조건·검증 방법·제외 범위·의존성을 넣는다. 운영자가 작업을 수락해야 기존 Development 상태로 초기화한다.
8. 필요하면 작업 초기화 전 운영자가 검증 프로필과 재작업 예산을 지정한다. 모델은 검사 실행 파일을 설치하지 못한다.
9. 같은 설정의 기존 개발 명령으로 제출·실제 검사·수동 검수·후속 작업 준비를 진행하고 `report`에서 상태를 합쳐 본다.

## 실제 확인한 흐름

### 정상 경로

`작은 매장의 재고와 유통기한을 관리하고 싶어`라는 모호한 TEST/STUB 요청에 고정 질문·답변을 연결했다. 로컬 저장·유통기한 요구 두 개와 웹/결제 제외 범위의 Scope를 승인한 뒤, Fake 기획 v2를 최종 승인했다. 저장 작업과 이에 의존하는 만료 작업이 생성되고 상태는 각각 ready/pending이 됐다.

추가 시험에서는 저장 작업에 운영자 프로필을 붙였다. TEST/STUB 작업 보고만 제출했을 때는 검수 승인이 거부됐다. 임시 `storage.txt`와 실제 Node assertion 명령으로 근거를 수집한 뒤에도 상태는 awaiting_review였고, 명시적 완료 조건 검수 후에만 approved 및 후속 작업 ready가 됐다. 이 파일은 실제 재고 제품이 아니라 시험용 문자열이다.

### 실패·중단 경로

- 잘못된 승인 ID·버전·revision, 누락 답변, 이미 답한 질문 수정, 기존 프로젝트 덮어쓰기를 거부했다.
- 잘못된 모델 JSON, 필수 요구 누락·제외 요구 참조·순환 의존성·이미 완료된 작업·경로 탈출·모델 검증 프로필을 거부했다.
- Scope 위반, 추가 질문 필요, 반복 한도, 오래된 Reviewer 버전은 중단 상태를 유지하고 승인·작업 분해·기획 자동 재실행을 허용하지 않았다.
- 모델 요청 중 프로젝트 잠금으로 중복 호출을 거부하고 오류 후 잠금을 해제했다.
- Scope 결정 저장 직후 또는 개발 초기화 직후 중단된 상황을 주입하고 명시적 재시도가 중복 작업 없이 완료됨을 확인했다.
- TEST/STUB 성공 주장에 실제 종료코드 1이 반환되면 재작업 예산 0인 작업이 한도 차단됐다. 보고에는 실패 근거 1, 차단 1, 선행 대기 1, 미검증 1, 전체 완료 false가 표시됐다.
- 승인 출처가 더 이상 현재 기획에 해당하지 않으면 보고의 sourceCurrent/completed가 false이고 다음 행동이 STOP이었다.
- 별도 Node 프로세스에서 전체 CLI 순서를 실행했고, live 설정으로 바꾼 뒤에도 보고 명령은 ADC 없이 동작했다.

## 이번에 실행하지 않은 것

- Cloud에 로컬 ADC가 없어 실제 Gemini 질문·Scope·작업 제안을 호출하지 않았다. 기존 Windows 기획 시험을 이번 통합 시험으로 대신 계산하지 않았다.
- 실제 사용자 Scope·Plan 승인을 새로 기록하거나 사용자의 로컬 `.adtf`를 변경하지 않았다.
- 개발·테스트 팀원 Runtime을 실행하지 않았다. 검사 명령은 테스트 러너가 운영자로서 준비한 것이다.
- Windows에서 새 CLI를 직접 실행하지 않았다. 테스트의 CLI spawn과 실제 검사는 Cloud Linux에서 실행했다.
- 신규 Gemini 제안 호출의 토큰 집계, 기획 중단 자동 복구, Scope 변경 승인 후 재개, 푸시 알림을 구현하지 않았다.
