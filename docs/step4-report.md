## 구현 결과

지휘자 기반에 선택형 검증 프로필과 실제 근거 수집을 추가했다. 현재 승인 Plan/Scope, 작업·제출 결과·담당자 지정 시도에 근거를 연결한다. 근거가 통과해도 완료 조건의 수동 검수를 받아야 작업을 승인한다.

파일 누락·검사 실패는 품질 재작업으로, 명령 누락·시간/출력량/경로/환경 문제는 차단으로 처리한다. 한도 차단은 상태 초기화로 우회할 수 없다. 프로필 없는 기존 작업은 기존 수동 의미를 유지한다.

새 검증에서 확인한 경우:

- 실제 Node 검사 명령의 종료코드·출력, 입력/산출물 해시와 시도 연결

- 예산 0 또는 소진 시 차단, 수동 blocked/pending 변경으로 한도 우회 거부
- 도구 누락·시간 초과·출력량 초과·작업공간 부재·파일 크기 한도 차단
- 프로세스 시그널 종료를 성공으로 오인하지 않음
- 절대 경로·경로 이탈·외부 심볼릭 링크 거부
- 명령 인수의 셸 구문을 문자열 그대로 전달, 상속된 테스트 비밀 환경 변수 제외, 일반 토큰 표기 가림
- 검증 후 산출물 또는 선언한 테스트 파일 변경 시 승인 거부
- 검사 중 선언 파일 변경 시 종료코드 0이어도 차단
- 다른 작업·시도·기획·제출 결과의 증거 및 불완전한 증거 거부
- 검사 중 중복 실행 및 상태 쓰기 차단, 승인 출처 변경 시 상태 커밋 거부

## 지휘자 테스트 계획과의 관계

SUP-08의 근거 누락, SUP-09의 보고와 실제 검사 불일치, SUP-10의 한도 차단, SUP-12의 도구 누락 판단 중 실행 가능한 정책을 fixture로 검사했다. 요구 질문부터 제품 기획·지시서·종합 보고까지 포함한 SUP 전체 시나리오를 수행한 결과는 아니다.

재고·유통기한 제품을 실제 개발하거나 개발 팀원 Agent를 실행하지 않았다. Gemini 기획 품질도 이번 단계에서 새로 측정하지 않았다. Windows 프로세스 종료 경로는 직접 실행하지 않았다.
