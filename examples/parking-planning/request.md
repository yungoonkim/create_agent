# 내 주차 위치 기록

혼자 웹 브라우저에서 주차한 위치를 적고 나중에 차를 찾을 수 있는 도구의 기획안을 작성한다. 현재 주차 중인 기록은 한 개만 둔다. 위치와 주차 시각을 기록하고 메모는 선택 사항이다. 차를 찾으면 표시하고 이전 기록을 보관한다. 잘못 적은 기록은 수정·삭제할 수 있어야 한다. 브라우저를 닫았다 다시 열어도 내 컴퓨터에 기록이 남아야 한다.

기획에는 사용자가 실제로 누를 버튼과 입력할 내용, 정상 흐름, 실패했을 때 기존 기록을 보존하는 동작, 따라 해볼 수 있는 확인 사례를 쉬운 한국어로 적는다. 기술 설계는 뒤에 분리한다. 이번 시험은 기획과 검토까지만 진행한다. 제품 코드 작성, 팀원 Agent 실행, 최종 사용자 승인 자동화는 하지 않는다.
