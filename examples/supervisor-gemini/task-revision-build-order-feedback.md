인수시험 진행자의 추가 의존성 점검이다. 현재 정상화된 숫자 제약, CLI 명령/플래그/경로/종료 규칙, 저장 실패 경계, 실행 예와 요구 추적은 유지한다. package.json과 tsconfig.json 및 최소 빌드/테스트 실행 설정이 task-04-cli-interface에만 배치되어 있어, 먼저 완료·검증되어야 하는 parser/storage/domain 작업이 독립적으로 타입 검사와 테스트를 실행할 수 없다. 이 최소 빌드·테스트 기반 산출물은 task-01-parser-and-validation에서 먼저 제공하도록 옮기고 완료 조건·검증 방법에도 반영한다. task-04는 기존 기반 위에 CLI 실행용 설정만 보완하게 하며, 선행 테스트를 후행 작업의 완료에 의존시키지 않는다. 새로운 Scope나 기능은 추가하지 않는다.
